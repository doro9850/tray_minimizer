# 트레이 최소화 (Windows)

선택한 프로세스의 창을 최소화하면 작업 표시줄 대신 **트레이 아이콘**(해당 프로그램의 아이콘)으로 보냅니다.

## 실행

```
pip install -r requirements.txt
python main.py
```

## 아이콘

창 타이틀과 제어 트레이 아이콘은 `ico/tray_minimizer.ico` 를 사용합니다(main.py 와 같은 폴더 기준).
파일이 없으면 기본 아이콘으로 대체됩니다. 트레이로 보낸 각 창의 아이콘은 해당 프로그램의 아이콘이 자동 지정됩니다.

## 사용법

- 목록에는 **현재 실행 중**이며 창이 있는 프로세스만 표시됩니다 (`%SystemRoot%` 아래 Windows 프로세스 제외).
- 체크한 프로세스가 대상이며, 변경 즉시 `%APPDATA%\TrayMinimizer\settings.json` 에 저장됩니다.
- 재시작하면 저장된 대상이 자동 적용됩니다. 대상 프로그램이 아직 실행 전이어도 이후 실행 시 적용됩니다.
- 여러 프로세스(그리고 한 프로세스의 여러 창)를 동시에 트레이로 보낼 수 있습니다.
- 트레이 아이콘 클릭/더블클릭 또는 우클릭 > 복원 으로 창을 되돌립니다.
- 설정 창을 닫아도 백그라운드에서 계속 동작합니다. 종료는 제어 아이콘 우클릭 > 종료.
  (종료 시 트레이에 숨겨진 창은 모두 자동 복원됩니다.)

## 구조

| 패키지 | 책임 |
| --- | --- |
| `app/config` | 설정 모델, JSON 저장소, 대상 집합(`TargetStore`) |
| `app/winapi` | Win32 ctypes 바인딩 및 래퍼 |
| `app/window` | 창 조회/제어, 최소화 이벤트 훅 |
| `app/process` | 프로세스 정보, 경로 해석, Windows 프로세스 필터, 스캐너 |
| `app/icons` | 실행 파일 아이콘 |
| `app/tray` | 창별 트레이 아이콘 |
| `app/core` | 트레이 최소화 서비스, 선택 컨트롤러 |
| `app/ui` | 메인 창, 목록 위젯, 제어 트레이 아이콘 |
| `app/application.py` | 객체 조립 |
